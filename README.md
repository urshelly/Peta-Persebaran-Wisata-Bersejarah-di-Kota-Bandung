# Peta-Persebaran-Wisata-Bersejarah-di-Kota-Bandung
menampilkan lokasi berbagai objek wisata sejarah dan cagar budaya yang tersebar di Kota Bandung, seperti museum, bangunan bersejarah, situs perjuangan, dan peninggalan kolonial. Peta ini bertujuan memberikan informasi spasial untuk mendukung edukasi, pelestarian warisan budaya, penelitian, serta pengembangan pariwisata sejarah.
